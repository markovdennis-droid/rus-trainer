# Варианты

| Файл | Что это |
|---|---|
| `v1.json` | Вариант 1 — источник правды, его читают валидатор и сборщик |
| `v1.js` | То же самое для браузера, собирается скриптом |
| `index.json` | Список вариантов |

## Почему два файла на один вариант

Тренажёр должен открываться и с диска двойным кликом, и с GitHub Pages.
Браузер не отдаёт локальный JSON через `fetch` — блокирует политикой
источника, — а `<script src>` отдаёт. Поэтому JSON заворачивается в `.js`,
который кладёт данные в `window.VARIANTS`.

Правим **только JSON**, затем пересобираем:

```
python3 -I tools/build_variants.py
python3 -I tools/validate_variant.py bank/variants/v1.json
```

## Как устроен вариант

```json
{
 "texts": {
   "A": { "for": [1,2,3],        "sentences": ["…"] },
   "B": { "for": [23,24,25,26,27], "sentences": ["…"] }
 },
 "tasks": [
   { "no": 4, "stem": "…", "opts": ["…"], "key": ["124"], "exp": "…" }
 ]
}
```

- `text` у задания — к какому тексту оно относится (`"A"` или `"B"`)
- `key` — массив: несколько допустимых ответов (задание 1 принимает
  «следовательно», «итак», «значит», «таким образом»)
- `match: "exact"` — отключает сверку без учёта порядка. Нужно там, где
  ответ это **один номер предложения**: иначе «71» зачтётся вместо «17»
- `left` / `right` — для заданий 8 и 22 (соответствие)
- `drill` — тренировочный режим: `letters` (вставить буквы) или
  `commas` (расставить запятые)
- `problem` и `author_position` — для задания 27

Тип ответа и балл задаются не здесь, а матрицей в `bank/spec.json`.
Валидатор сверяет вариант с ней и ругается, если ключ не того типа,
ссылается на несуществующий вариант ответа или на предложение, которого
нет в тексте.

## Два текста, а не один

В варианте два текста: короткий обслуживает задания 1–3, большой —
задания 23–27. Задание 22 (изобразительно-выразительные средства) стоит
отдельно и к тексту не привязано.

## Происхождение содержания

Задания и тексты авторские. Из демоверсии ФИПИ взяты только структура,
типы ответов и правила начисления баллов — это документ, а не
произведение. Языковой материал (ударение, паронимы, формы слова) —
факты языка, см. `bank/README.md`.

**Тексты в этом варианте — временные.** Решено брать классику из
общественного достояния (авторы, умершие до 1956 года: Чехов, Короленко,
Куприн). Достать её дословно из рабочей среды не удалось — выход во
внешнюю сеть закрыт, а восстанавливать текст по памяти нельзя: неточность
сломает задания, которые ссылаются на номера предложений. Поэтому тексты
написаны свои.

Чтобы подставить классику, нужен файл с точным текстом. Заменяются только
`texts.A` / `texts.B` и задания 1–3 и 23–27, которые на них опираются.
Задания 4–22 от текста не зависят и остаются как есть — это 22 линии
из 26.
