# Тренажёр ЕГЭ по русскому языку — демо для учителя

Статический прототип: откройте `index.html`, затем «Как пользоваться демо». Полный маршрут показа и пример сочинения — в [HOW-TO.md](HOW-TO.md) и `guide.html`.

| Файл | Назначение |
|---|---|
| index.html | Главная, тарифы, описание продукта |
| trainer.html | 8 заданий, тренировка, экзамен, сочинение |
| teacher.html | Кабинет, проверка К1–К10, замечания |
| guide.html | Инструкция в браузере |

Тарифы: 990 ₽/год самостоятельно; 1290 ₽/год через своего репетитора, из них 300 ₽ репетитору и 990 ₽ сервису до налогов и комиссий. Кабинет бесплатный. Задания 1–26 проверяются по ключам без ИИ. ИИ-разбор №27 — отдельная необязательная покупка. Репетитор проверяет все К1–К10 без покупки ИИ.

Работы, оценки и замечания кабинета сохраняются в localStorage этого браузера. Черновик ученика при обновлении сбрасывается. Передача работы реализована через фрагмент URL между страницами в одном браузере.

Нет сервера, входа, оплаты, активации доступа, реальных выплат и настоящего ИИ. Обратная доставка результата ученику не подключена. Для работы на разных устройствах потребуется серверная реализация.

Все HTML-файлы оставьте в одной папке. Для демонстрации сохранения используйте локальный HTTP-сервер либо GitHub Pages (Settings → Pages → Deploy from a branch → main, /root). `.nojekyll` включён. Перед публикацией для реальных учеников учителю нужно проверить задания, критерии и правила начисления баллов по действующим официальным документам.
